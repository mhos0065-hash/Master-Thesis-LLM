1. **Compute Borough Metrics**: For each borough in the trip-level data, calculate the following:
   - Departures: Count the number of trips that started in each borough (use the `StartBorough` column).
   - Self-contained trips: Count the number of trips that both started and ended in the same borough (use both `StartBorough` and `EndBorough` columns).
   - SelfContainmentRatio: Calculate as Self-contained trips / Departures.
   - Arrival share: Calculate as the number of trips ending in that borough divided by the total number of trips (use `EndBorough`).
   - Expected self-contained trips: Calculate as Departures x Arrival share.
   - SelfContainmentIndex: Calculate as Self-contained trips / Expected self-contained trips.

2. **Prepare Adjacency Weights**: From the borough adjacency list, create a row-standardized weight matrix (w_ij) where each entry is 1 divided by the number of neighbors of borough i.

3. **Compute Global Moran's I**: Using the SelfContainmentIndex values and the weight matrix, compute Global Moran's I using the formula provided: 
   \[ I = \frac{n/S_0 \cdot \sum_i \sum_j w_{ij}(x_i - \bar{x})(x_j - \bar{x})}{\sum_i (x_i - \bar{x})^2} \]

4. **Permutation Test for Significance**: Shuffle the SelfContainmentIndex values across boroughs at least 200 times, recompute Moran's I for each shuffle, and calculate the p-value as the fraction of shuffled I values that are greater than or equal to the observed I.

5. **State Findings**: Report whether significant positive clustering was FOUND (p < 0.05 and I > 0) or NOT FOUND, and provide the computed I, p-value, and the metric used as evidence.
