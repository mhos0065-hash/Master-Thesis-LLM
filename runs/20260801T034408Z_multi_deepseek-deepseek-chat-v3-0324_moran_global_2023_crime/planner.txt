1. Load the crime rate data (column: 'crime_rate') and neighbor relationships (columns: 'borough' and 'neighbor') into pandas DataFrames
2. Construct a binary spatial weights matrix W where W[i,j] = 1 if borough i and j are neighbors, 0 otherwise (including diagonal)
3. Calculate Global Moran's I using the formula: 
   I = (N/W0) * ΣΣ w_ij * (x_i - x̄) * (x_j - x̄) / Σ(x_i - x̄)²
   where N is number of boroughs, W0 is sum of all weights, x_i is crime rate, x̄ is mean crime rate
4. Perform permutation test (500+ shuffles) to calculate p-value by randomly shuffling crime rates and recomputing Moran's I each time
5. Compare original Moran's I to permutation distribution - if original I is in top/bottom 2.5% of distribution (p < 0.05), conclude spatial correlation exists

Acceptance criteria:
- Verify weights matrix is symmetric and has zero diagonal
- Check that mean-centered crime rates sum to zero
- Confirm permutation test uses ≥500 iterations
- Validate p-value calculation against expected two-tailed test
