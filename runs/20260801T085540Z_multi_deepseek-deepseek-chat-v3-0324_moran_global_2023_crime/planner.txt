1. Load the crime rate data (borough names and crime rates) and the neighbor list (pairs of boroughs that are adjacent)
2. Create a spatial weights matrix (binary adjacency matrix) where w_ij = 1 if boroughs i and j are neighbors, 0 otherwise
3. Implement Global Moran's I calculation using the formula:
   I = (N/W) * ΣΣ w_ij*(x_i - x̄)*(x_j - x̄) / Σ(x_i - x̄)²
   where N=number of boroughs, W=sum of all weights, x=crime rates, x̄=mean crime rate
4. Perform a permutation test (500+ shuffles) to calculate p-value by:
   - Randomly shuffling crime rates across boroughs
   - Recalculating Moran's I for each shuffle
   - Comparing original I to the distribution of shuffled I values
5. Check if p < 0.05 to determine significance and report Moran's I and p-value in FINAL ANSWER format
