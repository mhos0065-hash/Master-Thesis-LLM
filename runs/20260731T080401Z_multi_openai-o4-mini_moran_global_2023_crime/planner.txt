1. Load the borough-level dataset and extract the “borough” and “crime_rate” columns; load the adjacency list of borough neighbor pairs.
2. Construct a 33×33 spatial weight matrix W where W[i,j]=1 if borough i and borough j are neighbors (0 otherwise), then row-standardize W so each row sums to 1.
3. Using the crime_rate vector x and weight matrix W, compute Global Moran’s I: I = (n/ΣiΣj W[i,j])·(x–x̄)ᵀ W (x–x̄)/(Σi(xi–x̄)²).
4. Perform a Monte Carlo permutation test (e.g. 999 random permutations of x) to obtain a p-value for Moran’s I.
5. Check: if Moran’s I > 0 and p < 0.05, conclude clustered; otherwise conclude not clustered.
