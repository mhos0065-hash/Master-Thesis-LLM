1. **Prepare spatial weights matrix**: Extract unique boroughs from crime data, sort alphabetically, and map to indices. Construct a symmetric binary adjacency matrix `W` (33x33) using the neighbor list: set `W[i,j]=1` and `W[j,i]=1` for each neighbor pair, diagonal=0.  
2. **Compute observed Moran's I**: Align crime rates with sorted boroughs. Calculate:  
   - `y_mean = np.mean(y)`  
   - `z = y - y_mean`  
   - `denom = np.sum(z**2)` (if 0, skip to step 4)  
   - `S0 = np.sum(W)`  
   - `numerator = np.sum(W * np.outer(z, z))`  
   - `I_obs = (len(y) / S0) * numerator / denom`  
3. **Permutation test (500 shuffles)**: For each shuffle:  
   - Permute `y` to `y_perm`  
   - Recompute `I_perm` using `y_perm` (same `denom`/`S0`)  
   - Count if `I_perm >= I_obs`  
   - `p_value = (count + 1) / 501`  
4. **Conclusion**: If `denom==0`, output "CLUSTERED (I=1.0, p=0.0)". Else, if `I_obs > 0` and `p_value < 0.05`, "CLUSTERED"; else "NOT CLUSTERED".  

**Acceptance checks**:  
- `W` symmetric, diagonal=0.  
- Exactly 500 permutations.
