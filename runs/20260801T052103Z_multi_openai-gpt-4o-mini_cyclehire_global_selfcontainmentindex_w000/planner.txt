1. Compute the number of departures for each borough by counting the trips that started in each borough (use the StartBorough column).
2. Compute the number of self-contained trips for each borough by counting the trips where the StartBorough is the same as the EndBorough.
3. Calculate the arrival share for each borough by dividing the number of trips that ended in that borough (count from EndBorough) by the total number of trips.
4. Compute the expected self-contained trips for each borough using the formula: Departures x Arrival share.
5. Calculate the Self-Containment Index for each borough as: Self-contained trips / Expected self-contained trips. Then, use this index to compute Moran's I and perform a permutation test with at least 500 shuffles to assess spatial clustering, reporting the Moran's I value and p-value.
