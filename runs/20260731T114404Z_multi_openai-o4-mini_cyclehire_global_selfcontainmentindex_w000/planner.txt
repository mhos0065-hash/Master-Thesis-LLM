1. Aggregate the trip data by StartBorough and EndBorough (using columns StartBorough, EndBorough) to compute for each borough B:
   a. Departures[B] = count of trips with StartBorough = B  
   b. SelfContained[B] = count of trips with StartBorough = B and EndBorough = B  
2. Compute for each borough B:
   a. Arrivals[B] = count of trips with EndBorough = B  
   b. ArrivalShare[B] = Arrivals[B] / (total number of trips in the dataset)  
3. For each borough B compute:
   a. ExpectedSelfContained[B] = Departures[B] * ArrivalShare[B]  
   b. SelfContainmentIndex[B] = SelfContained[B] / ExpectedSelfContained[B]  
4. Read the borough adjacency list to build a spatial weights matrix W (binary contiguity: Wij = 1 if boroughs i and j share a border, else 0).  
5. Calculate Global Moran’s I on the vector {SelfContainmentIndex[B]} with W, perform a permutation test (e.g. 999 permutations), and check:
   – If p-value < 0.05 ⇒ conclude clustered;  
   – Else ⇒ conclude not clustered.
