1. Load the crime rate data (column with crime rates) and neighbor list (pairs of boroughs that are neighbors)
2. Create a binary spatial weights matrix W where W[i,j] = 1 if boroughs i and j are neighbors, 0 otherwise
3. Calculate Global Moran's I using the formula: 
   I = (N/W0) * ΣΣ w_ij*(x_i - x̄)*(x_j - x̄) / Σ(x_i - x̄)^2
   where N is number of boroughs, W0 is sum of all weights, x_i is crime rate, x̄ is mean crime rate
4. Perform permutation test (500+ shuffles) to calculate p-value by:
   a. Randomly shuffling crime rates while keeping W fixed
   b. Recalculating Moran's I for each shuffle
   c. Comparing original I to distribution of shuffled I's
5. Check if p-value < 0.05 and Moran's I > 0 (positive spatial autocorrelation) to determine clustering
